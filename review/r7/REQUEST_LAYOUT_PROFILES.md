# Explicit ChooseMove request profiles (source only)

Parent: PR155 exact 11e35393c9283f84f75976eabedb565788e02864. This is a source-model ABI change, not a native installer.

Recovered historical N6 and N50 archives independently record a complete original 44-byte actor0 command19 copy. N20 additionally ties selected slots to original PP stores. Verified N50 complete copied request has the same SHA256 as N6's first request; independent N50 repeat matches. Prefix offsets 0..3 header, 4..11 four little-endian move IDs, 12..15 current PP, 16..19 max PP agree with the existing source model and original source field order. Treat remaining 24 bytes as opaque, compare all of them; do not infer their internal layout. The older R10 verifier's parse_hex40 and normalize_store inspect a fixed 40-byte window, not the original copier length or all 44 stores. Its observations do not establish a separate native 40-byte ABI.

Keep legacy source40 as the zero/default profile, add explicit current44 profile with exact length, reject other lengths or unknown profiles. Require profile continuity across both original reads and the Fight ticket. Never truncate, pad, infer profile from a buffer length, or reinterpret its opaque tail. Original header, move identity, PP, legality, ownership, lease and target checks remain required. This increases C structure sizes; recompile callers together. An actual provider must independently authenticate exact engine identity, producer/copy length, owner, freshness and complete request and choose the profile; an enum is not proof. No live provider, native emission, manual-fallback proof or native acceptance is added. All production flags remain false.
