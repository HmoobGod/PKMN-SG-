## New source-only validator

`tools/verify_original_controller_copy_lineage.py` checks the exact recorded ROM + save identity, one instrumented marker, raw original console/candidate/PP STOP parity, monotonic CPU timestamps, no host battle-confirm after movement, actual original CPU entry/epilogue with source=dest SHA256 and length 6, chronological original move/target commit marker PCs, original actor0 PP decrement and later Main clear. Its result is `ORIGINAL_EXACT_ROM_ORDERED_PLAYER0_CONTROLLER_COPY_PP_CANDIDATE_ONLY` and **never** certifies engine-issued request ownership. It deliberately does not substitute result enums, move legality, controller source-LAB execution or request epochs for temporal markers. A deliberately fabricated internally consistent transcript remains possible; this is an audit, not a cryptographic attestation of real guest CPU execution.

`tools/test_verify_original_controller_copy_lineage.py` includes **20 public synthetic regression cases**, including mismatched original STOP streams, run ID, source/dest SHA, EWRAM path, missing action, wrong PP actor or decrement, bad clock, extra host action and intentionally coherent synthetic transcript that must still report `NOT_PROVEN`. The CI command is part of Source checks. Actual original CPU event data remain private in Drive and are **not** embedded in public GitHub.
